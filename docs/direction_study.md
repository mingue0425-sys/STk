# 방향 예측력 점검 (2026-11-20, v0.8)

## 왜 했나
공개 사이트의 1개월 예측 239건 중 238건이 '횡보'였고, 상승확률은 47~55% 사이에만 있었습니다.
그사이 NVDA 는 2주 동안 약 27% 내렸습니다. 판정이 원래 움직일 수 없는 구조인지, 쓸 만한 방향 신호가 있는지 확인했습니다.

## 1. 판정이 움직일 수 있는 구조인가 — 거의 없음
- 기본 기대수익률 = 무위험이자율 + 베타 × 5% (연 9~13% 수준). 추세 반영은 예전 백테스트에서 효과가 없어 기본으로 꺼져 있습니다.
- 로그정규 근사로 21거래일 상승확률이 55%를 넘으려면 연 변동성 30% 종목은 연 +18% 이상, 50% 종목은 +34% 이상의 기대수익률이 필요합니다.
  변동성 차감(σ²/2) 때문에 실제로는 50% 근처에 머뭅니다. 즉 1개월 '횡보' 판정은 구조상 거의 고정입니다.

## 2. 쓸 만한 방향 신호가 있나 — 견고한 신호 없음
결과를 보기 전에 정한 기준: 관심종목 20개, 21거래일 간격의 겹치지 않는 시점 117개(2017-02 ~ 2026-10),
**앞 절반과 뒤 절반 기간 모두 같은 부호이고 각각 t > 2** 일 때만 채택. 같은 날 20종목은 함께 움직이므로 날짜별로 묶어서 검정.

## 3. 실제 모델의 상승확률은 예측력이 있나 — 없음
공개 사이트와 같은 기본 설정으로 1개월 워크포워드 백테스트 (20종목 × 107개 시점 = 2,140건, 2017-12 ~ 2026-10).
비교 기준은 '그 시점까지 그 종목이 21일 동안 오른 비율'(상수 예측).

| | Brier 점수 (낮을수록 좋음) |
|---|---|
| 모델 상승확률 | 0.2469 |
| 과거 상승 비율 (기준) | 0.2445 |
| 항상 50% | 0.2500 |

- 날짜별로 묶은 차이: 앞 절반 t=−0.85, 뒤 절반 t=+0.16 → 기준보다 낫다고 볼 근거 없음
- 상승확률 구간별 실제 상승 비율: 47~49% → 56%, 49~50% → 59%, 50~52% → 60%, 52~54% → 59%, 54%+ → 61% (거의 평평)
- 실제 상승 비율 59.7% vs 모델 평균 52.1%: 모델이 낮게 잡는 편이지만, 관심종목이 '지금까지 잘 오른 종목'이라 실제 비율도 부풀려져 있습니다(생존 편향).
- **범위는 잘 맞음**: 50% 구간 적중 49.3%, 90% 구간 적중 90.4%, 평균 PIT 0.55

6개월은 겹치지 않는 시점이 10년에 약 20개뿐이라 방향 예측력을 판단할 수 없습니다.

## 결정
- 모델은 바꾸지 않음 (사전 기준을 통과한 신호가 없음 — 바꾸면 범위 보정만 흐트러질 위험)
- '방향성 약한 횡보 흐름' → **'뚜렷한 방향 우위 없음'** 으로 문구 변경. '횡보'는 주가가 제자리일 것처럼 읽히지만,
  실제 뜻은 '오를지 내릴지 판단할 근거가 없다'입니다. 범위·위험·국면을 중심으로 보도록 사이트에 안내 추가.
- 흐름 변화 표시는 문구가 아닌 방향 코드로 비교 (문구 변경일에 모든 종목이 '변화'로 표시되지 않게)
